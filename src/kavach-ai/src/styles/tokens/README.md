# KAVACH AI Design Tokens Repository

This directory contains the single source of truth (SSOT) design tokens for the KAVACH AI Companion and Orb interface.

## Repository Map

* `schema.json`: System versioning, platform compatibility, and schemas definition.
* `colors.json`: Raw hex color tokens for all FSM states.
* `semantic.json`: Contextual color mapping (e.g. `processing`, `critical`, `attention`).
* `motion.json`: Easing constants, spring definitions, and durations.
* `physics.json`: Physical parameters for levitation (gravity, stiffness, damping, friction).
* `orb.json`: Glass constants, viewport dimensions, and rendering quality profiles.
* `face.json`: Eye and mouth geometry rig settings.
* `audio.json`: Vocal context loops and status sounds.
* `haptics.json`: Android/iOS haptic vibration tokens.
* `accessibility.json`: High contrast multipliers and motion reduction overrides.
* `breakpoints.json`: Responsive viewport bounds in pixels.
* `layers.json`: Absolute composting Z-index layout constraints.
* `themes/`: Theme directories (`dark.json`, `emergency.json`).
